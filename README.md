# PurpleTeamV4

Public artifacts for the **Advanced Purple Team Course — Version 4**.

Lab materials are organized by module under `Labs/`. Each lab folder contains the interactive exercise plus the instructions students need to complete it.

## Links

Curated external references that complement the course modules. These are not required to complete the labs, but expand the conceptual background.

- **[Threat Modeling Worksheet — Security Journey](https://www.securityjourney.com/hubfs/Threat%20Modeling%20Worksheet%20-%20Security%20Journey.xlsx)** *(xlsx)*
  A lightweight worksheet that walks through assets, trust boundaries, threat actors, attack surface, and mitigations in spreadsheet form.
  **Aligned with Module 1 — Planning, Mapping & Engagement Design.** Use it as a warm-up before Lab 1.1 (Engagement Planner) to practice translating an organization profile into a structured threat picture, or as a take-home companion for students who want to apply the planning mindset to their own environment after the course.
